| Tệp | Nội dung | Dùng ở |

## 📷 Danh sách ảnh nên bổ sung (tùy chọn)

Chạy ứng dụng (`start.bat` hoặc `python run.py`), vào từng tab và chụp màn hình rồi lưu vào thư mục này với tên gợi ý dưới đây. Sau đó bỏ comment dòng ảnh tương ứng trong `README.md`:

| Tên tệp gợi ý | Nội dung cần chụp |
| :--- | :--- |
| `devices-filter.png` | Tab 1: bộ lọc Tất cả/Online/Offline + ô tìm kiếm + đặt tên thân thiện (nút ✏️) |
| `adapter-info.png` | Thông tin card mạng Wi-Fi (SSID, BSSID, sóng %) hoặc Ethernet (Gigabit, Duplex, MTU) |
| `traffic-chart.png` | Tab 2: biểu đồ lưu lượng & băng thông thời gian thực |
| `connections.png` | Tab 3: giám sát socket TCP/UDP kèm tiến trình & dịch vụ |
| `packets.png` | Tab 3: bảng gói tin bắt được thời gian thực |
| `soc-center.png` | Tab 4: sự kiện cảnh báo an ninh (thiết bị lạ, cổng nguy hiểm...) |
| `system-logs.png` | Tab 5: nhật ký hệ thống |
| `isp-lookup.png` | Hộp thoại Opt-in tra cứu ISP / Public IP |

> 💡 **Mẹo chụp ảnh đẹp cho README**: giữ Privacy Mode bật (mặc định) để không lộ IP thật; chụp ở độ rộng ≥ 1400px; định dạng PNG.
